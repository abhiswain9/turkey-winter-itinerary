# Turkey Winter Escape – Interactive Itinerary

Sample 9-night Istanbul itinerary (Dec 25 – Jan 3) as a single-page interactive web app.

## Features
- Expandable day-by-day plan
- Interactive map of key sights
- Practical tips (weather, transport, NYE)
- Checkable packing list
- Fully responsive + print-friendly

## Live Demo
Deployed via Vercel from this repo.

## How it was built
Static HTML + Tailwind CSS (CDN) + Leaflet map + vanilla JS.
